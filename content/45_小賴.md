#personalIntroduction
技術講師，曾任新創團隊 tech lead 與接案團隊負責人
::

::speaker-summary
#speechAbstract

- 你曾遇過辛苦完成功能後，交付時卻被說：「這不是我要的！」
- 你曾開會時滿頭問號，覺得為什麼使用者、PM、工程師為什麼都不好好說「人話」嗎？
- 想把事情做好，卻總是卡在「彼此的理解不一樣」？

在軟體開發的世界裡，最難的不是寫程式，而是搞懂對方在說什麼。 一個沒有被釐清的需求，永遠無法被正確實作。

但其實沒有人錯，只是沒問對問題， 所以這場工作坊我們不講程式、不談框架， 我們要一起練習「怎麼問對問題、怎麼確認共識、怎麼避免誤解」。 從日常的專案對話出發，學會成為能引導對話、釐清需求的工程師。 一起從「這不是我要的」走向「原來我們想的一樣」。

::

::speaker-audience
#targetAudience

- 想學會與 PM、設計師或使用者「說同一種語言」的網站工程師
- 常被需求變更困擾的前端、後端或全端開發者
- 想提升溝通與對齊能力的 PM / 技術主管
- 想讓「每一次討論都更有效」的跨職能團隊成員

::

::speaker-earnings
#expectedEarnings

- 清楚掌握工程師未來可能的成長方向與職涯抉擇
- 能在不同角色之間找到共同語言，提高協作效率
- 具備能夠讓需求討論更聚焦、更快速對齊的實戰方法
- 理解如何在不增加工時的情況下，降低需求變更帶來的風險與焦慮

::
