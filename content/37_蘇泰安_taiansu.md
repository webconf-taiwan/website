#personalIntroduction
三年電腦雜誌技術編輯，十五年全端開發，八年程式教學與顧問，工作經歷橫跨美日新多國廠商。自 Rails 1.0 開始參與社群，現為 Elixir Taiwan Co-organizer, Functional Thursday Steering Committee, 孩子們的程式小聚主辦人。近來在研究教育、親子溝通與 AI 相關的題目
::

::speaker-summary
#speechAbstract
此講題將介紹當下最適合個人開發的技術棧：Phoenix LiveView 讓後端直接推送 UI 更新到前端，從此無視前後端分離的阻礙。結合 Elixir 創始人打造的 Tidewave mcp Server，讓程式碼生成不再單純是矇眼打靶。在這個 AI 工具每週更新的時代，個人開發者需要的不是反覆疊加更多工具，而是減少過程及環節間的阻力。未來的工作流樣貌已經在 Elixir 生態成型，一起來現場見證它如何運作。
::

::speaker-audience
#targetAudience
前後端開發者
::

::speaker-earnings
#expectedEarnings

1. 瞭解 Phoenix LiveView + Tidewave 生態系的開發體驗，認識其優缺點，以及為何它是最適合個人開發或小團隊的技術棧。
2. 看懂 Phoenix 框架, LiveView 套件及 Tidewave 的核心功能，重新思考如何評估 AI 時代開發工具鏈，以及帶走能在立即套用到自己工作流中的開發思維。

::
