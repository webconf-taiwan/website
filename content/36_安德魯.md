::speaker-intro
#personalIntroduction
現任職於大型軟體開發團隊的架構師，負責核心產品的服務化，與內部產品開發團隊的架構改善等任務。在過去的 25 年工作經驗，主要都專注於 .NET 開發 SaaS，B2B2C 的雲端服務。我專長的領域包括: 軟體工程，物件導向設計，分散式系統架構設計，平行處理，API 設計 及 微服務導向架構設計 (microservices) 等。而近年 AI 快速崛起，我也投入了相關研究。擅長的主題包含: Agent 架構設計，MCP 的設計開發，Context Engineering 等領域。

我樂於分享技術新知與開發的經驗，常在各大研討會或是在社群活動上分享經驗。同時我也有撰寫部落格文章的習慣，希望能累積我的經驗給需要的夥伴們。我深信知識是越分享越精進的，這也是支持我自 2004 至今連續 20 年不間段分享文章的動力來源。

個人經歷:

- 現任 91APP，首席架構師 Chief Architect
- 榮獲 Microsoft MVP 微軟最有價值專家 獎項，2016 ~ 2025
- 擔任多次 Microsoft Azure Cafe，TechDays，TechEd，DevOpsDays Taiwan，.NET Conf 等大型研討會講者，與相關 Azure PaaS 雲端系列課程與企業內訓講師

::

::speaker-summary
#speechAbstract
過去十年，SaaS 靠「服務代管」與「API First」改寫了 Web 產品的樣貌，不用安裝、不用維運、註冊就能立即啟用，透過訂閱與 seat 計價，複雜的軟體系統變成能立即啟用的線上服務。
::

::speaker-audience
#targetAudience
本場次適合負責 SaaS 或雲端產品的產品經理、技術主管、系統架構師與後端工程師，也非常適合正在評估導入 AI / Agent 的產品團隊與創業者。只要你有在設計或維運 SaaS 服務、或正在思考「我的服務要怎麼接到客戶自己的 Agent 裡」，這一場都能幫助你整理下一步的方向。
::

::speaker-earnings
#expectedEarnings
與會者將理解 SaaS 如何從以 API 為主的系統整合思維，轉向以 MCP First 為核心的 Agent 賦能，實際學習把既有服務拆解成可被 Agent 調用的技能 (Tools / Skills / MCP)，並理解這樣的設計改變會如何影響產品邊界、使用者體驗與成效評估方式。
::
