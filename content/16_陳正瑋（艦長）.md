::speaker-intro
#personalIntroduction
表面上是只會在臉書釋放夫妻閃光文的愛妻家，私底下其實是默默關注新知的技術愛好者。平時熱衷關注 DevOps 相關新知與技術，期盼未來人人都可以像畢凱艦長一樣用嘴巴叫所有主機做事！工作之餘參與技術社群，目前擔任 GitLab Hero、DevOps Taiwan Community 志工；曾擔任《Effective DevOps》繁體中文版譯者，在第 11 屆 iT 邦幫忙鐵人賽中以《和艦長一起 30 天玩轉 GitLab》系列文獲得 DevOps 組冠軍，並出版同名書籍。

個人部落格 https://chengweichen.com

重新認識 DevOps https://effectivedevops.tw
::

::speaker-summary
#speechAbstract
寫完 Code，然後呢？是把東西丟給維運團隊，然後開始祈禱上線不出包？還是你已經厭倦了總是在救火、解 bug，被動處理那些部署後才浮現的爛攤子？

這場演講，讓我們從開發者的視角，去看懂包含在 DevOps 內的各種常見關鍵字，這些關鍵字背後的思維是什麼。讓我們理解，學習 DevOps 不該只是學習「如何操作工具」，而是一場職涯角色的進化。讓我們從被動的「碼農」，蛻變為能真正為產品交付負責的關鍵人物。
::

::speaker-audience
#targetAudience
開發者、軟體工程師、身處軟體開發維運團隊內的每一份子、想知道軟體開發除了寫 Code 之外還需要學什麼的人
::

#expectedEarnings
