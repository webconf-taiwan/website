::speaker-intro
#personalIntroduction
一個喜歡研究手帳筆記術與時間管理，寫過 WordPress 與手帳書籍的前端工程師。從小學六年級開始製作網站到現在，依然專注於以使用者為中心的前端介面開發，擔任過學校（台大、北科大、世新大學）與企業教育訓練（中華電信、1111 人力銀行等）的前端講師，以及 WebConf、MOPCON、廣州 FEDAY 等的技術講者。

樂於學習新技術並分享知識，從 2008 年建立部落格 MUKI space\* 至今，內容涵蓋前端技術文章、數位筆記軟體使用心得、AI 應用與讀書筆記。

::speaker-summary
#speechAbstract
你是否也曾為了某個小功能而 npm install 一個肥大的套件？在瞬息萬變的前端生態中，瀏覽器原生 Web API 的能力已遠超我們的想像，但「不知道它的存在」或「不確定如何正確使用」往往讓我們選擇了更熟悉、卻也更臃腫的第三方函式庫，導致專案的 Bundle Size 與維護成本不斷攀升。

這次演講會直面工程師在開發中遇到的真實挑戰，分享何時該果斷擁抱原生，何時該慎選套件，並透過 MCP 工具協助分析程式碼，推薦最好的 API 組合。
::

::speaker-audience
#targetAudience
希望減少專案對第三方函式庫的過度依賴，尋求原生解決方案的開發者
::
